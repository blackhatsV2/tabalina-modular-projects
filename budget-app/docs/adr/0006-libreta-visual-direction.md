# Visual direction: "Libreta" (passbook ledger), not a fintech dashboard

Budget Buddy's first screens needed a visual identity before any screen got built, and the brief was explicit about what to avoid: a generic SaaS dashboard look, which would read as cold and intimidating to a first-time budgeter. Three directions were proposed — a bank-passbook ledger ("Libreta"), a calm coastal "Iloilo Morning" built around a time-of-day horizon strip, and a "Teacher's Ledger" built around Jayrold's own grade-book vernabular (blue-black ink for normal, red pen reserved for the one thing needing attention). Decided on Libreta as the base — paper and ink, hairline rules instead of card shadows, a circular rubber-stamp badge for status — with two elements borrowed from the other two and restyled to fit it: Teacher's Ledger's margin-note style for ⓘ explanations (inline under the row on mobile), and Iloilo Morning's horizon strip, repurposed to mark today's position within the current pay period, redrawn in ink-on-paper with no gradient.

Several engineering constraints were folded into the direction rather than left as later polish: status is always a stamp *plus* a text label (OK / Low / Short), never color alone, so the design degrades for colorblind users without a separate accessibility pass. The brass/gold color (the "Low" state) is fill-only with dark ink text on top — it never appears as text directly on the paper background, since at that lightness it fails WCAG AA as a text color. Every color pairing actually used for text or for the hairline rule was checked against its paired background to clear AA (≥4.5:1 for text, ≥3:1 for the rule, treated as meaningful row-separating structure rather than pure decoration). Dark mode ("passbook-cover green" / night ledger) follows `prefers-color-scheme` now; a `[data-theme]` override attribute is already wired into the tokens so a manual toggle (a later Settings-screen feature) can be added without retouching the palette.

Fraunces (display) and IBM Plex Sans (everything else, including tabular-figure money columns) are self-hosted via `@fontsource`, Latin subset only — no third-party font requests, so the app keeps working offline, in the Android APK, and under the CSP already locked down in `vercel.json`. Fraunces is spent on exactly one hero number per screen (ADR-aligned with "spend boldness in one place," not a rule specific to this ADR but the reason the display face never appears twice on the same screen). All of this lives as CSS custom properties in `src/styles/tokens.css` — one file, so the palette, type scale, and spacing scale can be adjusted later without hunting through components for hardcoded values.
